## 先搞清一件事：优惠码绑的是"线路 + 周期"，不是品牌

DMIT 卖的是 VPS，产品线按网络质量分三档：

| 系列 | 简称 | 回程线路 | 定位 |
| --- | --- | --- | --- |
| Premium | Pro | 三网 CN2 GIA | 对大陆访问质量有硬要求 |
| Eyeball | EB | 联通 9929 / 移动 CMIN2 | 预算优先，兼顾大陆体验 |
| Tier 1 | T1 | 纯国际 BGP，无大陆专项优化 | 国际业务、备份、中转 |

同一个机房、同样配置的一台机器，挂 Pro 和挂 T1 是两个不同商品、两个不同编号，价格差能到几倍。优惠码就是挂在这一层的。

所以正确的使用顺序是：**先定机房 → 再定线路 → 再定付款周期 → 最后填码**。反过来做，一定是白填。

## 怎么在结算页验证一个码到底能不能用

流程很短，但有一步很多人会漏：

1. 选定机房和套餐，点进配置页
2. 在 **Billing Cycle** 下拉里先选好付款周期——月付 / 季付 / 半年付 / 年付
3. 页面上会出现 **Apply Promo Code** 输入框，把码贴进去
4. 点 **Validate Code**
5. **别只看"验证通过"这四个字，去看右侧订单总价有没有变**

第 5 步是关键。有些码验证时通过，但因为订单周期不满足条件，实际不产生折扣。价格没变就是没生效，换下一个码试，不用怀疑人生。

另外一个现象：优惠码框里不要带空格，直接从本文复制粘贴，很多人是复制的时候把尾部空格也带进去了。

## 常见问题

**Q：为什么我填了码，Validate Code 也通过了，价格没变？**
大概率是付款周期不满足条件。绝大多数码明确写了"季付及以上"或"年付"，月付订单填进去验证能过，但不打折。把周期切到季付或年付再看价格。

**Q：同一个码能反复用吗？**
带 `RECURRING` 的循环码是作用在账单周期上的，续费时继续生效。非循环码一般只作用于当次订单。这也是为什么值得优先找循环码。

**Q：WEE 系列为什么没有码？**
WEE 是补货时放出的特价库存机，本身就是低价入口，不参与优惠码活动。有第三方明确写了"优惠码：无需优惠码"。

**Q：DMIT 什么时候放码放得最多？**
从公开记录看，黑五、圣诞、618 这类节点是主要窗口。平时折扣码数量少、频率低，但常驻的循环码一直能用。

**Q：支付方式有哪些？**
支付宝、微信支付、PayPal 和信用卡都支持，国内用户付款不折腾。
